# ARAL — дизайн-система (Design System)

Источник истины — утверждённые HTML-черновики в `pages/` (без изменений).
Этот документ описывает дизайн-систему, которую эти файлы реализуют.

## 1. Цвет

Общий набор переменных шести страниц (V8, Водители, Партнёры, Преимущества, Интересное, Контакты):

| Токен | HEX | Роль |
|---|---|---|
| `--blue` | `#0756a1` | бренд, ссылки, активный пункт меню, основные кнопки |
| `--navy` | `#06346c` | заголовки, подвал, активные вкладки, тёмные плашки |
| `--bright` | `#1680d4` | акцентные линии, маркеры, фокус |
| `--ice` | `#f2f7fc` | фон чередующихся секций, плитки мобильного меню |
| `--line` | `#dae5ef` | границы карточек и разделители |
| `--ink` | `#19334e` | основной текст |
| `--muted` | `#60758b` | вторичный текст, неактивные пункты меню (`#63778d`) |
| `--paper` | `#ffffff` | фон страницы |

Каталог (revision 15) использует собственную близкую палитру: `--blue #003c98`, `--blue2 #0a58cf`,
`--deep #0b1c38`, `--mist #f3f6fa`, `--yellow #ffe425`. Главная — `--gold #ffd337` на синем градиенте
`linear-gradient(122deg, #04255f, #0046b6, #0d68cf)`.

Жёлтый (`#ffe425` / `#ffd337`) — единственный тёплый акцент: CTA на тёмном фоне, счётчики, бейджи.

## 2. Типографика

Системный стек `system-ui, -apple-system, "Segoe UI", Arial, sans-serif`, без веб-шрифтов.

| Элемент | Значение (десктоп → 680px) |
|---|---|
| Логотип `.brand` | 31 → 28px, 880, `letter-spacing: -.075em`, `--navy` |
| H1 героя | ~77px → 65px, жирный, плотный интерлиньяж |
| H2 секции | ~50px → 37px |
| Надстрочник `.tag` / `.kicker` | 10–11px, UPPERCASE, разрядка, синий, с линией |
| Текст `.copy p` | 15–16px, `line-height: 1.78` |
| Меню | 12px, 670, `#63778d`, активный — синий с нижней линией 3px |


## 3. Сетка и ритм

| Токен | Значение |
|---|---|
| `.container` | `min(100% - 80px, 1180px)`; 950px → поля 24px; 680px → поля 18px |
| Каталог | `--max: 1390px` |
| `.section` | ~100px по вертикали; 73px на 950px; 66–76px на 680px |
| Колонки | `.two-col` (текст + визуал), карточные сетки 2–4 колонки → 1 колонка на 680px |
| Брейкпоинты | 1060 (меню переносится под логотип), 950, 680 (мобильное меню), 400/360 |

Секции чередуют белый и `--ice`; финальные блоки — тёмно-синие.

## 4. Компоненты черновиков

| Компонент | Классы | Где |
|---|---|---|
| Шапка | `.nav`, `.nav-wrap`, `.brand`, `.menu`, `.nav-toggle` | все страницы |
| Подвал | `.foot`, `.foot-inner` | все страницы |
| Герой | `.hero`, `.hero-wrap`, `.hero-copy`, `.hero-visual`, `.hero-caption` | Компания, Преимущества, Интересное |
| Навигация по разделам | `.adv-summary`, `.mini` | Водители, Партнёры, Преимущества |
| Хронология | `.years`, `.year-btn`, `.year-detail` | Компания |
| Статьи | `.story-grid`, `.story-card`, `.story-toggle`, `.story-details` | Интересное |
| Темы | `.adv-topic`, `.topic-media`, `.xmf-comparison` | Преимущества |
| Карта | `.network`, `.tabs`, `.pin`, `.side`, `.city-choice` | Партнёры |
| Справочник | `.cc-directory`, `.cc-tab`, `.cc-result`, `.cc-detail` | Контакты |
| Каталог | `.product-card`, `.filters`, `.catbtn`, `.active-chip`, `.compare-table`, `.floating-compare` | Продукция |
| Кнопки | `.ghost-btn` (синяя), `.btn-secondary`, `.btn-yellow`, `.btn-outline` | все |

Мобильное меню (680px): кнопка «☰ Меню», пункты — плитки 2 колонки на `--ice`
(1 колонка при 360px), активная плитка с синей рамкой.

## 5. Движение

Короткие переходы цвета 0.14–0.2s, появление панелей 0.3s, `prefers-reduced-motion` отключает анимации.

## 6. Доступность

Ссылка «К содержанию», фокус на контент после перехода, объявление заголовка страницы,
`aria-expanded`/`aria-pressed`/`role="tab"` в механиках черновиков, клавиатура на карте,
мобильное меню «☰ Меню» с `aria-expanded`.
