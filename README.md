# ARAL — сайт из утверждённых черновиков

Сайт собран из семи утверждённых страниц **без изменений**: файлы черновиков лежат в `pages/`
байт в байт как исходники (контрольные суммы — в [SOURCES.md](SOURCES.md)). Оболочка `index.html` + `shell.js`
показывает нужный черновик на весь экран и связывает между собой их меню и ссылки.

## Разделы

| Меню | Адрес | Черновик |
|---|---|---|
| Компания | `#/company` | `pages/v8.html` (раздел `company`) |
| Продукция | `#/catalog`, `#/product/ARAL-001…017`, `#/compare` | `pages/products.html` (revision 15) |
| Для водителей | `#/drivers` | `pages/drivers.html` (черновик 08) |
| Для партнёров | `#/partners` | `pages/partners.html` (черновик 11) |
| Преимущества ARAL | `#/advantages` | `pages/advantages.html` (черновик 04) |
| Интересное | `#/interesting` | `pages/v8.html` (раздел `interesting`) |
| Контакты | `#/contacts`, `#/where` (магазины) | `pages/contacts.html` (черновик 03) |

Подробнее: [docs/SITEMAP.md](docs/SITEMAP.md), [docs/DESIGN_SYSTEM.md](docs/DESIGN_SYSTEM.md).

## Что делает оболочка (и только это)

- Открывает черновик по адресу `#/<раздел>`; стартовая страница — Компания (первый пункт меню).
- Пункты меню черновиков (в части файлов они без ссылок) ведут в соответствующие разделы.
- Ссылки черновиков на прежний сайт `alexalp9.github.io/ARAL-/#/…` ведут в разделы этого сайта.
- Переходы внутри каталога (карточка, сравнение) отражаются в адресе; работают «Назад/Вперёд», обновление и прямые ссылки.
- Внешние ссылки, телефоны и почта открываются в окне браузера, а не внутри фрейма.

Внутри черновиков ничего не меняется: вёрстка, тексты, фото, анимации и механика — исходные.
